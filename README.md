# NEXUS GAMING — موقع أخبار ألعاب بأخبار مباشرة

الخادم يجلب الأخبار تلقائياً من الإنترنت (Google News بالعربية عبر RSS) ويحدّثها كل 10 دقائق، والصفحة تعيد التحميل كل 5 دقائق.

## التشغيل
```
npm install
npm start
```
ثم افتح: http://localhost:3000

## الملفات
- `server.js` — Express + rss-parser، ونقطة `/api/news` مع كاش.
- `public/index.html` — الواجهة العربية RTL.

## التخصيص
- غيّر المصادر من مصفوفة `FEEDS` في `server.js` (أي رابط RSS يعمل).
- غيّر مدة التحديث من `TTL`.
- إذا تعذّر الاتصال، تعرض الصفحة أخباراً تجريبية احتياطية.

## النشر
يعمل على أي استضافة Node.js (Render / Railway / VPS): شغّل `npm start` وحدّد المتغير `PORT` إن لزم.
